# Sitio web profesional — Juan Carlos Alvear Sepúlveda

Este repositorio contiene un sitio estático construido con [Eleventy 3](https://www.11ty.dev). Los contenidos se administran con [Pages CMS](https://pagescms.org) y el sitio se publica automáticamente en GitHub Pages mediante GitHub Actions. También es compatible con Netlify y Vercel.

- **Publicación y administración:** ver [GUIA-ADMINISTRACION.md](GUIA-ADMINISTRACION.md).
- **Antecedentes y decisiones editoriales:** ver [MATRIZ-ANTECEDENTES.md](MATRIZ-ANTECEDENTES.md).
- **Desarrollo local:** `npm install` y luego `npm run serve` (requiere Node.js 22).
- **Logotipos para documentos y presentaciones:** `src/assets/img/logo-horizontal.png`, `logo-horizontal-blanco.png` y `logo-monograma.png`.

Propietario de los contenidos y de la identidad digital: Juan Carlos Alvear Sepúlveda.
